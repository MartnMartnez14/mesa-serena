# Privacidad · Mesa Serena

Actualización: 4 de octubre de 2026. Autor: Martín Martínez García (Bluffer).

La aplicación guarda altura opcional, preferencias, hábitos, fechas, notas, peso y cintura opcionales y favoritos en IndexedDB del navegador. No hay cuentas ni servidor de datos personales. La aplicación no transmite esos registros, no incluye analítica, anuncios, rastreadores, fuentes remotas ni widgets de pagos.

El código y el catálogo son públicos; los registros del usuario no forman parte del repositorio. El alojamiento GitHub Pages registra direcciones IP para seguridad al cargar recursos: https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages . Los enlaces de fuentes, perfil y reportes abren sitios con sus propias políticas. No les agregamos datos del diario.

No existe cifrado adicional dentro de la aplicación. Quien accede al dispositivo y a la sesión del navegador puede acceder al diario. Otros proyectos en el mismo origen GitHub Pages comparten el ámbito de almacenamiento del navegador; nombres diferentes de base de datos no impiden que código del mismo origen la lea. Este producto no debe utilizarse como archivo clínico confidencial.

Exportar crea un JSON sin cifrar. La aplicación no lo sube, pero el destino elegido puede sincronizarlo mediante servicios del usuario. Importar reemplaza todo el estado personal después de validar y confirmar. Eliminar todos los datos restablece el estado local, pero no borra exportaciones previas ni garantiza borrado forense de los soportes físicos.

No hay recuperación por cuenta. Borrar el almacenamiento, perder el equipo o cerrar navegación privada puede eliminar los registros. La persistencia depende del navegador. Hacer copias privadas regularmente y conservar acceso seguro al dispositivo.

La opción de ocultar mediciones es una preferencia visual, no un borrado. No ingreses datos de terceros. Esta herramienta está dirigida a adultos y no solicita fecha de nacimiento ni diagnósticos.

Contacto: perfil público del autor e issues del repositorio. No publiques datos de salud ni respaldos al pedir ayuda.
